
# Customer Churn Prediction System

A machine learning project that predicts customer churn using customer data and provides insights through an interactive dashboard.

## Project Objectives
- Analyze customer churn patterns.
- Build and evaluate machine learning models.
- Predict the probability of customer churn.
- Visualize customer retention insights.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Matplotlib

## Key Features
- Customer data analysis
- Churn prediction
- Model performance evaluation
- Interactive dashboard
- Customer retention insights
